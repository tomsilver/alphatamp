## Key findings & recommended v3 ranges

- **Block height.** Feasible full-height (current grasp): **tall section 0.05–0.23 m**, **short section 0.05–0.05 m**. The short section's usable height is set by the **gripper's vertical clearance above the block** (~0.10 m of room is needed ABOVE the block to place it), NOT the 0.15 m shelf clearance.
- **Grasp scheme.** The production *current* scheme (height-adaptive, fixed-world grasp z) gives the widest feasible range; the naive *center* / *capped-center* grasps the user proposed FAIL placement more (a lower grasp point worsens the place reach-in). **The controller is already flexible to variable heights — do not switch to a center grasp.**
- **⚠️ Caveat — the short section is effectively CUBE-ONLY.** Only the 0.05 m block places in the short section (the next height, 0.07 m, already fails), because the gripper needs ~0.10 m above the block and the short clearance is only 0.15 m. **This is too tight for v3's goal of sampling a *range* of heights near a short/tall cutoff in the short section** — v3 will need either a **taller short-section clearance** (env change) or an **adjusted short-section place approach** to admit a meaningful height range. As-is, v3's height variation is a **tall-section** story (0.05–0.23 m) with the short/tall decision being 'cube vs taller'.
- **Block width.** Graspable-face ceiling = the finger aperture **≈ 92 mm** (nominal 85 mm). The kinematic sim is width-PERMISSIVE (it 'picks' absurd widths because the target is collision-excluded during the reach-in), so **v3 must cap width analytically in the generator** — recommend a safe max face width ≈ **0.08 m** (≈0.9× aperture). It still places across the band up to ≈ 0.19 m wide.
- **Packing padding (left-to-right).** The empirical min edge-to-edge gap between adjacent blocks (M4, real placement vs a tall neighbour) is **33–50 mm** — **~5–8× the naive finger-thickness estimate**, because the finger+knuckle assembly and the reach-in motion (not the pad) bind. M3 finger-overhang lower bound 44–53 mm. **Recommend v3 pack with an edge gap ≥ 60 mm** (measured max + ~10 mm safety); n-in-a-row validation seated 5/5 @ w=0.05, 5/5 @ w=0.07.

## Sweep 2 — graspable width

Finger aperture (inner-pad separation): **open 92.4 mm**, mid 52.9 mm, closed 7.9 mm (nominal 2F-85 stroke 85 mm).

**Pick (confound check).** Grasp = kinematic attach on the ±x faces; the target is
collision-excluded during the reach-in, so the sim does NOT bind width:

| 0.030 | YES | YES | 0.522 |

| 0.090 | YES | YES | 0.482 |

**Finding:** the kinematic sim pick succeeds up to full width 0.19 m (the widest tested) — it does NOT bind width, because the grasp attaches kinematically and excludes the target during the reach-in. The real graspable-width ceiling is the **finger aperture ≈ 92 mm** (nominal 85 mm). v3 must cap block width analytically; the sim will not reject an over-wide block at pick time.

## Sweep 3 — tight-packing padding (left-to-right)

Usable band = **0.522 m** (object-centre range). Neighbour height = 0.24 m (worst case).

**Method 1 — capacity arithmetic** (edge gap if n blocks share the band):
| width (m) | n | edge gap = (band − n·w)/n (m) |
|---|---|---|
| 0.050 | 4 | 0.0805 |
| 0.050 | 5 | 0.0544 |
| 0.070 | 4 | 0.0605 |
| 0.070 | 5 | 0.0344 |

**Method 2 — gripper geometry (naive)**: from the finger-pad thickness alone (6.35 mm; closed inner-pad separation 7.9 mm) you would guess a single neighbour-side finger needs only ≈ **6–8 mm** beyond the block face. **The empirical methods below overshoot this ~5–8×** — the binding geometry is the whole finger+knuckle assembly plus the diagonal reach-in swept volume, not the pad thickness.
